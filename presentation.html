ORAEX

Modernização de Monitoramento Oracle

De Scripts Legados para Automação DBRE Inteligente

Cliente: Getnet | Fevereiro 2026

1. O Desafio (Antes) 🕸️

  • Legado Crítico: Scripts em Shell antigos e complexos.
  • Manutenção Difícil: "Espaguete code", difícil de debugar.
  • Baixa Visibilidade: Logs dispersos em texto (`grep`).
  • Risco Operacional: Execuções sem controle e falhas silenciosas.

2. A Solução ORAEX 🚀

Transformamos scripts isolados em uma Plataforma de Automação.

  • ✨ Core em Python: Moderno e Modular.
  • 🛡️ DBRE Concept: Reliability Engineering.
  • 🚜 Compatibilidade Total: Roda em RHEL 6/7/8.
  • 📊 Observabilidade: JSON Logs & Dashboard.
$ python run_healthcheck.py --json

3. Arquitetura Robusta 🏗️


graph LR
    A[Cron/Systemd] --> B(Orquestrador Python)
    B --> C{Módulos Core}
    C -->|Diagnóstico| D[Oracle DB]
    C -->|Limpeza| E[File System]
    B --> F[Logs JSON]
    F --> G[Dashboard Web]
    F --> H[Grafana/Zabbix]

*Modular, Resiliente e Sem necessidade de Root.

4. O Que Foi Entregue 📦

Componente Função
oracle_healthcheck.py Diagnóstico unificado do Banco (Locks, RMAN, TDE).
asm_capacity.py Predição inteligente de estouro de disco.
housekeeper.py Limpeza segura (Dry-Run) de logs/homes.
Dashboard Web Visão executiva em Dark Mode.

5. Segurança & Compliance 🛡️

✅ Zero Root: Tudo roda com usuário `oracle`.

✅ ReadOnly: Scripts de diagnóstico apenas leem.

✅ Safe Mode: Modo de manutenção e checagem de processos.

✅ Zero Dependency: Refatorado para Python 3.6 nativo.
